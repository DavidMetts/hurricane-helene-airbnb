# Hurricane Helene and Asheville Airbnb

Did Hurricane Helene (September 2024) affect Asheville Airbnb listings, reviews and pricing? Individual course project for DSA 8660, Clemson University, spring 2025.

## Files

- **Airbnb final project (PDF and PowerPoint)**: the full report and slides.
- **Airbnb project .tfl**: Tableau Prep flow that extracts, cleans, joins and unions quarterly Inside Airbnb files into a single table (900k+ rows, 2012 onward).
- **NLP_study.ipynb**: pandas and NLTK count of "hurricane" mentions in review text by date.
- **HURDAT.ipynb**: GeoPandas and Folium overlay of the NOAA storm track on Asheville neighborhoods.
- **plot_Airbnb.ipynb**: supporting plots.

## Data

Inside Airbnb (listings, reviews, neighbourhoods GeoJSON) and NOAA IBTrACS hurricane track. Data files are not included.
